# MusiJuegos · Musicala

Portal web estático para mostrar los videojuegos musicales de Musicala en formato de catálogo interactivo.

## Archivos incluidos

- `index.html`: estructura principal de la app.
- `styles.css`: estilos visuales, responsive y diseño Musicala claro.
- `app.js`: datos de juegos, filtros, buscador, ordenamiento y detalle pedagógico.

## Cómo usar

1. Copia estos archivos en una carpeta.
2. Agrega el archivo `logo.png` en la misma carpeta raíz.
3. Sube la carpeta a GitHub Pages o abre `index.html` localmente.

## Notas

- El juego `Atrapa el ritmo` venía duplicado en la lista original y se dejó una sola vez.
- La app no usa backend, Firebase ni Sheets. Es una primera versión liviana y fácil de mantener.
- Para agregar más juegos, edita el arreglo `games` en `app.js`.
